# MailAlarm (v3)

Будильник на письма с инцидентами для ночных смен. Заходит в почту по IMAP (по умолчанию Яндекс),
ищет **непрочитанные** письма во всех папках и играет мелодию. Если сломалась почта, сеть или сам
скрипт, играет другую мелодию.

## Запуск

1. Нужен Python 3.9+ для Windows с python.org (tkinter в нём уже есть).
2. Двойной клик по `run_alert.bat`. Откроется окно настроек, рядом чёрное окно с логом.
3. В окне введи:
   * адрес ящика и **пароль приложения** (Яндекс ID → Безопасность → Пароли приложений → «Почта»);
   * от кого **не** звонить и какие папки **не** смотреть (по одной записи в строке);
   * как часто проверять почту (в секундах);
   * **мелодию для инцидента** и **мелодию для ошибки** (`.wav`, кнопка ▶ проигрывает для проверки).
4. Нажми «Сохранить». Настройки применяются сразу, перезапуск не нужен.

Крестик окна только сворачивает его, мониторинг продолжает работать. Остановить совсем можно кнопкой
«Выход» или Ctrl+C в чёрном окне. Кнопка «Стоп звук» глушит текущую мелодию.

## Что где хранится

Всё лежит в твоей домашней папке (`C:\Users\<ты>\`), в репозиторий не попадает:

| Файл | Что |
|---|---|
| `mail_alert_settings.json` | настройки; пароль зашифрован Windows DPAPI (привязан к твоей учётке) |
| `mail_alert_state.json` | какие письма уже звонили |
| `mail_alert.log` | лог |
| `mail_alert_hang.txt` | если скрипт завис, сюда пишется, где именно |

В коде нет ни почты, ни пароля.

## Как работает

* Письмо отслеживается по ключу «папка + UIDVALIDITY + UID». UID уникален только внутри папки, поэтому
  одинаковые номера в разных папках не склеиваются.
* Пока письмо не прочитано, звонок повторяется (`REMIND_EVERY_MIN`, по умолчанию каждые 5 минут, не дольше
  `REMIND_FOR_HOURS` = 3 часов). Прочитал с телефона, и звонки прекратились.
* Папки открываются только на чтение (EXAMINE), ничего не помечается прочитанным.
* Почта не отвечает 2 проверки подряд: играет мелодия ошибки, повтор не чаще раза в 5 минут.
* Watchdog: если основной цикл молчит 5 минут, играет мелодия ошибки и пишет стеки в `mail_alert_hang.txt`;
  ещё через 5 минут убивает процесс, а `run_alert.bat` поднимает его заново.
* Если для мелодии ошибки ничего не выбрано, играет мелодия инцидента. Если не выбрана ни одна или файла
  нет, будет сирена из бипов, чтобы не молчать.
* Вторая копия не запустится (чтобы звонки не дублировались).

Остальные параметры (сколько секунд играть, как часто повторять, смотреть ли INBOX, лимиты watchdog) лежат
константами в начале `yandex_alert_v3.py`.

## Советы на ночь

* Отключи сон компьютера: `powercfg /change standby-timeout-ac 0` и `powercfg /change hibernate-timeout-ac 0`.
* Проверь, что звук не замьючен, а устройство вывода нужное.
* Поставь активные часы для обновлений Windows, чтобы ночью не было перезагрузки.
